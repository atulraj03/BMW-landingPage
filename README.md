# 🚗 AURORA X5 - Responsive Car Landing Page

A modern and responsive landing page for the **AURORA X5**, a fictional electric vehicle.

This project was created as part of **Week 1: Responsive Landing Page Development** using HTML5, CSS3, and Vanilla JavaScript.

---

## 📌 Project Overview

The AURORA X5 landing page focuses on a clean, modern, and automotive-inspired design.

The website includes:

- Responsive navigation bar
- Hero section
- Car image and animation
- Features section
- About section
- Contact form
- Responsive mobile menu
- Smooth scrolling
- Hover effects
- Responsive layout for desktop, tablet, and mobile

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Flexbox
- CSS Media Queries
- Google Fonts - Montserrat

No external JavaScript frameworks or libraries are used.
